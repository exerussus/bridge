# most-relay — свой сервер-ретранслятор для Моста

Сервер нужен, когда голос между ПК не проходит напрямую или через Radmin идёт с большим пингом. Это **опция**:
без него Мост работает как раньше — напрямую и через Radmin. С ним WebRTC всё равно сначала пробует прямой путь,
а сервер подхватывает только то, что не прошло.

Что делает сервер: принимает голос и показ экрана по UDP 3478, TCP 3478 и TCP 443 и пересылает их собеседнику.
Содержимое он не видит — голос и экран шифрует сам WebRTC. Сервер знает только «от кого и кому» и сколько байт.

С 3.17 через него же работает **своя локальная сеть MostNet** (как Radmin VPN): у каждого ПК — адрес 10.77.0.x,
пакеты идут по UDP 3479 (или по TCP 443, если UDP не проходит) и шифруются от ПК до ПК.

Готовый файл: `relay/bin/most-relay` (Linux x86_64, без зависимостей — подходит любая Ubuntu/Debian).

## Ключи

- **Приглашение** (`MRI-…`) — для моста. Печатает `most-relay invite`. Живёт **5 минут** и срабатывает **один раз**:
  мост меняет его на свой постоянный ключ участника (он приходит зашифрованным и хранится только в настройках моста).
- **Мастер-ключ** (`MRM-…`) — для приложения «Сервер» в Мосте: участники, приглашения, настройки, журнал и
  **терминал root**. Печатает `most-relay master`. Им же можно подключить мост (многоразово). Берегите его как пароль
  root: кто знает мастер-ключ, тот управляет сервером. Сменить — `most-relay master --new` или кнопкой в приложении.

## Сервер

Подойдёт самый простой VPS: 1–2 ядра, 1–2 ГБ памяти. Важнее ядер — канал от 100 Мбит/с без жёсткого лимита трафика
и дата-центр поближе к вам. Система — Ubuntu 24.04.

## Установка (5 минут)

1. **Скопируйте файл на сервер.** С Windows проще всего так (в PowerShell, из папки проекта):

   ```
   scp relay\bin\most-relay root@<IP сервера>:/root/
   ```

   (или через WinSCP — перетащить файл в `/root`).

2. **Зайдите на сервер** и положите программу на место:

   ```
   ssh root@<IP сервера>
   mkdir -p /opt/most-relay
   mv /root/most-relay /opt/most-relay/
   chmod +x /opt/most-relay/most-relay
   cd /opt/most-relay
   ```

3. **Создайте настройки.** Внешний адрес сервер найдёт сам:

   ```
   ./most-relay init --name my-relay
   ```

   Он напечатает **мастер-ключ** — сохраните строку (её же покажет `./most-relay master`). Если он пишет «только
   внутренний адрес» — укажите внешний IP из панели хостинга: `./most-relay init --ip <IP>`.

4. **Включите службу** (автозапуск, перезапуск при сбоях, правила брандмауэра ufw):

   ```
   ./most-relay install
   ```

   Служба работает от root — так терминал в приложении «Сервер» может всё, что можно по SSH.
   Если у хостинга есть свой брандмауэр в панели — откройте там: UDP 3478, TCP 3478, TCP 443, UDP 3479,
   UDP 49152–65535.

5. **Подключите мост.** На сервере:

   ```
   ./most-relay invite
   ```

   В течение 5 минут вставьте строку в Мосте: «Соседи» → «Свой сервер-ретранслятор» → «Подключить». Должно появиться
   «на связи» с временем ответа сервера. Соседям отдельные приглашения не обязательны: включённое «Делиться с
   соседями» отдаёт им сервер само.

6. **Приложение «Сервер»** (по желанию): папку `publish\apps\most-relay-admin` (её собирает `build.cmd`) положите в
   папку `apps` моста, откройте приложение, разрешите его и вставьте мастер-ключ. Дальше приглашения, участников,
   настройки и терминал можно делать оттуда, без SSH.

Проверить, что сервер отвечает, можно и браузером: `http://<IP сервера>:443/` — покажет «most-relay … сервер-ретранслятор».

## Своя локальная сеть

1. Сервер — версии 3.17+ (обновление — ниже). Сеть включена по умолчанию (`netPort: 3479` в `relay.json`; 0 — выключить).
2. Каждый ПК подключён к серверу **своим** приглашением (`most-relay invite`) — сеть по «Делиться с соседями» не
   передаётся.
3. В Мосте: «Соседи» → «Своя локальная сеть» → «Установить службу» (подтвердить администратора) → «Включить».
4. Адрес ПК (10.77.0.x) виден там же; проверка — `ping 10.77.0.x` с другого ПК.

**Файлы через сервер (3.19).** В Мосте у «Свой сервер-ретранслятор» — галочка «Файлы и синхронизация с соседями —
через сервер»: файлы с соседями пойдут по своей сети. На сервере это можно запретить и ограничить скорость — в
приложении «Сервер» → «Настройки» или в `relay.json`: `"netFiles": false` — запретить, `"netMbit": 50` — не больше
50 Мбит/с на участника (0 — без ограничения; касается и игр). Файл перечитывается сам, перезапуск не нужен.

## Команды на сервере

| Команда | Что делает |
| --- | --- |
| `most-relay invite [имя]` | одноразовое приглашение (5 минут); без имени участник получит имя ПК |
| `most-relay master [--new]` | показать мастер-ключ (`--new` — сменить: старый сразу перестанет действовать) |
| `most-relay revoke <имя>` | отозвать: новые разговоры у него не начнутся, начатые закроются |
| `most-relay list` | участники и их трафик с запуска |
| `most-relay status` | сервер, участники, разговоров сейчас, служба |
| `journalctl -u most-relay -f` | журнал службы |
| `systemctl restart most-relay` | перезапустить |

Настройки — в `relay.json` рядом с программой (доступ только у root): порты (`udpPort`, `tcpPorts`, `relayPorts`),
лимит разговоров на участника (`maxPerMember`). После правки портов — `systemctl restart most-relay`. Участников и
мастер-ключ можно менять на работающем сервере: он перечитывает `relay.json` сам.

## Режимы в Мосте

- **Если напрямую не вышло** (по умолчанию) — прямой путь и Radmin пробуются первыми, сервер — запасной.
- **Всегда через сервер** — голос и экран только через сервер; собеседники не видят адрес вашего ПК.
- **Не пользоваться** — ни своим сервером, ни серверами соседей.
- **Делиться с соседями** — соседям уходит временный ключ (на сутки): сервер работает и у них без своей настройки.
  Их трафик сервер учитывает на ваше имя.

## Безопасность

- Ключ участника мост получает по одноразовому приглашению, зашифрованным (X25519 + ChaCha20-Poly1305): подсмотреть
  его в сети нельзя. Запросы моста подписаны этим ключом, повтор перехваченного запроса не пройдёт.
- Канал приложения «Сервер» зашифрован целиком (X25519, ключи шифрования — от мастер-ключа; ChaCha20-Poly1305),
  мастер-ключ по сети не передаётся. Без мастер-ключа канал не открыть и не подменить.
- Неудачные попытки подключения с одного адреса — не больше 20 в минуту.

## Обновление

С ПК (PowerShell; переменные — из инструкции установки):

```
scp "${env:MOST_BRIDGE_PROJECT}\relay\bin\most-relay" "${env:MOST_RELAY_USER}@${env:MOST_RELAY_HOST}:/root/most-relay.new"
ssh -i "$env:MOST_RELAY_KEY" "${env:MOST_RELAY_USER}@${env:MOST_RELAY_HOST}" "install -m 755 /root/most-relay.new /opt/most-relay/most-relay && rm /root/most-relay.new && systemctl restart most-relay && /opt/most-relay/most-relay version"
```

Или на сервере: скопировать новый файл поверх `/opt/most-relay/most-relay` и `systemctl restart most-relay`.

## Собрать самому

На Linux с Rust: `RUSTFLAGS="-C target-feature=+crt-static" cargo build --release -p most-relay --target x86_64-unknown-linux-gnu`.
